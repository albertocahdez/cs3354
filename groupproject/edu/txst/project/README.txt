# 16-Bit Maze Game - Team 4

## Custom Feature: Conveyor Belt Tiles

Our team implemented Conveyor Belt Tiles as a custom feature.

When the player steps onto a conveyor belt, the belt automatically moves the player one additional tile in the direction indicated by its arrow, provided the path is clear. The additional movement counts as one step.

## How to Test

1. Run the game using the MazeGUI class.
2. Open a maze level using File → Open.
3. Locate a cyan conveyor belt tile.
4. Move the player onto the conveyor belt.
5. Observe the automatic movement in the arrow's direction.
6. Check that the step counter updates correctly.
7. Continue playing until you reach the exit.
